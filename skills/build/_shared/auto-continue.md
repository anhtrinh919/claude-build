# Auto-continue — default to silence

Default: keep going, same turn. `AskUserQuestion` ends a turn on its own — a drilling round, an approval gate, a fork — nothing below adds to that list.

**Cross without stopping:** a stage's own authoring, implementation, and testing machinery once its questions are answered · a stage's clean return straight into the next stage's dispatch · backend's Step 1 → 2 → 3 → Completion, wave by wave · the join from `backend-complete` into `/build:review`. No "next I'll…", no permission-to-proceed, no pause narration, no treating a sub-skill's return as a place to wait.

**Reference, not license — a turn already ends here:** the constitution boundary · the Outcome Card gate, every phase · each phase-complete boundary · a genuine felt-impact fork (`voice.md`) · a cap-hit binary · the external design hand-off — wait for the user's return, never loop or fabricate.

**Showing the user something is not stopping.** A rendered mockup, a review finding, a passing check — show it and keep going.
